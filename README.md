# 💝 Be My Valentine? 💝

A cute, interactive Valentine's Day game where you can ask someone special to be your Valentine!

## 🎮 How It Works

- Click **"Yes!"** to accept and see a sweet celebration message 🎉
- Try to click **"No"** and watch it playfully run away from your cursor! 😄
- The more you avoid the "No" button, the bigger the "Yes" button becomes

## 🚀 How to Use

Simply host this on GitHub Pages:

1. Go to your repository Settings
2. Navigate to Pages section
3. Select your branch (usually `main` or `copilot/add-valentine-game`)
4. Save and wait a few minutes
5. Share the link with your special someone! 💕

Or open `index.html` directly in your browser to test it locally.

## ✨ Features

- 💖 Beautiful gradient background with floating hearts
- 🎨 Responsive design that works on mobile and desktop
- 🎭 Playful "No" button that dodges the cursor
- 🎊 Confetti celebration when "Yes" is clicked
- 💝 Sweet success message
